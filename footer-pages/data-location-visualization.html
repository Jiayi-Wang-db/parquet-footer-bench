All ordinals are zero-based; all intervals are half-open. Values are illustrative. The file strip shows only bytes [100, 4000).
Chunks stay in logical order within each column; different columns can have different chunk counts and interleave in the file. Local chunk numbers restart at 0; global cc indexes the column-major metadata.
The arrays shown are the decoded contents of streams located by StreamLocation; each descriptor’s own offset/length locates metadata bytes.
These five fields locate each chunk’s data pages. Metadata and any required dictionary are separate reads; dictionary associations come from ColumnChunkMetadata.dictionary_regions.
